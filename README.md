# Bali Nusra Business Command Center V3

## Update data
Replace the Excel files inside `data/` with the newest files using the same filenames. Open the app and click **Refresh data**. No dashboard rebuild is required.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publish
Recommended: GitHub + Streamlit Community Cloud. For internal business data, keep the repository/app private or publish only aggregated safe metrics.
