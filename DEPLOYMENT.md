# Deployment

1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, `.streamlit/config.toml`, and `data/`.
3. Deploy `app.py` with Streamlit Community Cloud.
4. Future update: replace Excel files in `data/`, then refresh/redeploy.

Do not publish raw customer-level data, phone numbers, MSISDNs, or other sensitive business information publicly.
